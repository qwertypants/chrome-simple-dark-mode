# arXiv screenshots

Captured 2026-10-28 from https://arxiv.org/ for the Shade Toggle homepage.

- `arxiv-light.png`: original page appearance.
- `arxiv-dark.png`: same page with the pinned, locally bundled Shade Toggle rendering adapter enabled.

The shared preview browser captured these PNGs at 1280 × 889 from a 1440 × 1000 CSS viewport. The site's temporary maintenance announcement was dismissed through its own button. No page content or colors were retouched. The preview used the compiled rendering test entry with a local message adapter; it did not install the extension or exercise its permissions/popup. These are visual examples, not installed-extension verification or a complete accessibility audit of arXiv. The renderer was disabled and the temporary tab closed after capture.
