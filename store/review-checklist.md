# Release review checklist

Preparation is local. Submission, approval and live installation are separate milestones.

- [x] Original provisional name Shade Toggle, local icons and draft listing.
- [x] MIT project license and full bundled dependency notice in source and ZIP.
- [x] Privacy policy and permission justifications drafted against manifest.
- [x] GitHub Pages homepage/privacy source and workflow prepared.
- [x] Installed Chromium fixture store screenshot and provenance prepared.
- [x] Unit/build/installed fixture tests and reproducible package recorded.
- [ ] Owner reviews exact ZIP/hash, name, listing, icon, screenshot and permissions.
- [ ] Owner enables repository private vulnerability reporting and reviews security route.
- [ ] Stable Chrome manually loads production dist, tests native permission prompt,
      denial/revocation, browser restart and uninstall cleanup on real sites.
- [ ] Owner authorizes push/deployment; enable Pages Actions in repository settings.
- [ ] Public homepage/privacy URL verified without authentication; remove pending text
      only after that check and keep policy source/page consistent.
- [ ] Owner supplies publisher identity/contact, accepts terms, verifies account,
      pays any registration fee, chooses countries/category/visibility.
- [ ] Recheck official policy/dashboard requirements and complete accurate disclosures.
- [ ] Owner explicitly authorizes store upload/submission of reviewed artifact.
- [ ] Store submission recorded as submitted/reviewing, with actual dashboard evidence.
- [ ] Approved public listing verified and store-distributed build installed/smoke-tested.

No current claim of publication, approval, universal accessibility or ADA certification.
