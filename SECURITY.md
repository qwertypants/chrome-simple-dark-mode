# Security reporting

Version 0.1.0 is a prerelease. Before distributing, complete the manual verification
matrix and store checklist. Only the latest development version currently receives fixes.

Report a vulnerability through GitHub's private vulnerability reporting on
https://github.com/qwertypants/chrome-simple-dark-mode/security/advisories/new
if enabled by the repository owner. This route has not yet been verified available.
If unavailable, open a minimal public issue requesting a private reporting channel,
without exploit details, private URLs, page content or credentials. The maintainer
must enable private reporting before inviting sensitive reports. No security response
SLA is promised. Do not publish sensitive details until a private route is established.
