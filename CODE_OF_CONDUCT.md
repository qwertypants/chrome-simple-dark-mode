# Code of conduct

Treat contributors and users with respect. Critique ideas and code, avoid personal
attacks, harassment, discrimination and disclosure of another person's private data.
These expectations apply to project issues, pull requests and discussions.

Maintainers may edit or remove abusive content and restrict participation. Report
conduct concerns to repository maintainers via GitHub; request a private route in a
minimal issue if the concern is sensitive. Do not include personal information in a
public report. Maintainers will consider context and handle reports discreetly where
GitHub's available channels permit. No response-time guarantee is offered.
